# CESAE Viagens ✈️

Website desenvolvido no âmbito de um trabalho prático de **Desenvolvimento Web**, com o objetivo de reproduzir um layout de uma página de viagens utilizando exclusivamente **Bootstrap 5.3**, sem CSS próprio.

## 🌍 Sobre o projeto

O CESAE Viagens é uma página demonstrativa de uma agência de viagens fictícia.
O projeto foi desenvolvido com foco na utilização dos componentes do Bootstrap e na adaptação do layout a diferentes tamanhos de tela.

## 🛠️ Tecnologias utilizadas

- HTML5
- Bootstrap 5.3

## 📁 Estrutura do projeto

```text
CESAE-Viagens/
│
├── index.html
│
├── img/
│   └── imagens dos destinos
│
└── icons/
    └── ícones utilizados no website
```

## 🚀 Como executar o projeto

1. Clonar o repositório:
2. Abrir a pasta do projeto.
3. Abrir o ficheiro `index.html` no navegador.

## 🎓 Contexto académico

Projeto desenvolvido como trabalho prático no âmbito da formação, com o objetivo de aplicar os conhecimentos de HTML5 e Bootstrap 5.3, nomeadamente a utilização de componentes, classes utilitárias e técnicas de layout responsivo.
